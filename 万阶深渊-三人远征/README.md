# 《万阶深渊：三人远征》

一个纯本地、无需安装与联网的横屏放置 RPG 原型。

## 启动方式

双击 `index.html` 即可开始游戏。建议使用最新版 Chrome、Edge 或 Firefox，并保持浏览器窗口宽度不低于 1180 像素。

## 核心规则

- 三名固定角色全自动战斗：王宇彤（铁壁守卫）、王尚（暗影游侠）、徐崇睿（星辉祭司）。
- 共 10000 关，每 10 关出现精英，每 100 关出现 Boss。
- 10 个地下城区域各有 3 种普通敌人与 1 个 Boss 种族；Boss 各有 10 次进化，共 100 个形态，并分别拥有撼地、钢壳、噬魂等标志机制。
- 普通关限时 12 秒，Boss 关限时 30 秒；Boss 失败后退回前一关，30 秒后自动重试。
- 战斗、金币培养、技能升级、装备换装与装备强化全部自动进行；玩家可以暂停自动成长。
- 任意关卡连续失败且永久收益足够时会智能重整；余烬按固定顺序自动点亮篝火星图，不需要选择构筑路线。
- 三名角色在 100 级技能精研、200 级技能觉醒；等级基础属性在 100 级后封顶，后续成长主要来自技能进化、培养、装备与篝火。
- 主战斗界面显示最近 3 条自动远征记录，可展开查看最近 30 条；普通培养合并统计，Boss 首胜、稀有换装与重整单独高亮。
- 网页在后台标签页时使用与前台一致的战斗规则继续推进；关闭网页后不推进关卡，但金币与经验最多累计 12 小时，重新打开时自动用于成长。
- 第 100 关解锁篝火重整与 2 倍速，第 1000 关解锁 4 倍速；默认自动使用当前最高倍速。
- 第 10000 关为明确终点，不开放第 10001 关；通关后可以经过二次确认重新开始完整远征。
- 共享规则的 8 个随机样本预计约 59～61 小时累计开页时间完成远征；100/200 级进化在全部样本中均可到达。

## 存档

进度每 5 秒自动保存到浏览器本地存储。v3 是全新数值版本，会按产品规则直接删除 v1 旧存档且不保留备份。设置页可以导出、导入同版本存档或清空进度；导入内容经过大小限制、字段白名单、数值边界与文本转义校验。

## 项目结构

- `index.html`：游戏界面结构
- `styles.css`：横屏像素风界面与动画
- `rules.js`：浏览器与平衡模拟器共享的关卡、角色、Boss 和成长纯规则
- `save-state.js`：存档初始值、字段级清洗与本地存储安全操作
- `game.js`：战斗时间轴、自动养成、掉落、重整和界面调度
- `assets-v3/heroes`：3 名原创角色的独立动作帧
- `assets-v3/enemies`：30 种普通敌人的独立动作帧
- `assets-v3/bosses`：100 个原创 Boss 进化形态
- `assets-webp/backgrounds`：10 张原创地下城背景
- `assets-webp/ui`：装备与功能图标
- `verify.mjs`：项目完整性检查
- `logic-test.mjs`：战斗、挂机、Boss机制、存档安全与转场时序回归测试
- `balance-sim.mjs`：使用共享规则的多随机样本通关分布模拟

生成源图、旧版图集与素材工具保存在远端 `art-source-v2` 归档分支，不进入网页发布包。

## 发行包

在仓库提交后运行 `powershell -ExecutionPolicy Bypass -File .\build-release.ps1`，会在被 Git 忽略的 `release` 目录生成网页 ZIP。发行包不包含 Git 历史、测试与模拟脚本；向玩家提供该 ZIP 或 GitHub 的分支下载 ZIP，可避免拉取旧素材历史对象。
